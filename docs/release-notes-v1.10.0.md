# v1.10.0 更新说明

## 这一版：让「等别人」不再占着你的逾期栏

七件事，都是日常用起来最硌手的地方。

### 1. 等待他人（新状态）

以前只有「待办 / 进行中 / 完成」，等对方回执的事只能一直挂在待办里，然后每天红着脸显示「逾期 5 天」——可它逾期与否根本不取决于你。

现在多一个**等待他人**：

- 在详情「安排」里点「等待他人」，或在命令面板里对选中的待办说一句
- 列表里显示橙色的「等对方」，**不计逾期、不进逾期统计**
- 聚焦页单独一段「等待他人」，和「即将逾期 / 本周 / 待办池」分开
- 对方有动静了就点回「待办」或「进行中」

### 2. 回收站

删掉的待办和速记不再直接消失，先进回收站：可以**还原**，也可以**彻底删**。侧栏和命令面板都能进。

### 3. 每日摘要

每天第一次打开工作台时，右上角弹一句：今天 N 件 · 逾期 M 件 · 等他人 K 件 · 预计 X。只弹一次，不打扰；点「看今天」直接跳过去。

### 4. 多选里补了「删除」和「改提醒」

Shift 连选之后，除了完成 / 改期 / 打标签 / 移分类，现在还能批量**移到回收站**、批量**设提醒或清提醒**。

### 5. 标签管理

侧栏「标签」标题旁的齿轮：改名（改成已有的名字就是**合并**）、删除。挂在待办上的标签删掉只是去掉标记，不会删待办。

### 6. 每月例行也能「跳过这一期」

以前只有每天 / 每周的滚动系列能跳。现在每个月那一期不想做，也能跳过一次：这一期标记成已跳过，后面的期次照常。

### 7. 命令面板能直接做事

Ctrl+K 之后不只是跳转：完成当前选中、推到明天、置顶 / 取消置顶、标为等待他人，都能直接在面板里执行。

## 怎么升级

1. 设置 → 版本与更新 → 检查更新（或等齿轮上的小红点）
2. 下载安装包，等进度到 100% 并显示「sha256 校验通过」
3. 从托盘退出工作台，运行下载好的安装包覆盖安装

数据库会从 v7 升到 v8（`task` 表放行 `waiting` 状态）。升级前会自动留一份 `workbench.db.pre-v8.bak`，出问题可以直接换回去。

## 已知限制

- 等待他人只是「不催你」，不会提醒你去催对方；想要这个可以等后面的「等待超时提醒」
- 回收站里的东西默认一直留着，不会自动过期；觉得占地方可以手动「清空待办回收站」
- 每日摘要只在每天第一次打开时出现，关掉就没有了，不会重复弹
