# v1.7.0

## 这一版改了什么

### 1. 速记独立成库

以前顶部那条输入框是「快速建待办」，回车之后它会变成一条任务，进收件箱、上日历、算逾期。现在它是一本**便签**：

- 侧边栏多了一个「速记」入口，和待办完全分开（存在独立的 `memo` 表里，不进任务列表、不进日历、不进统计、不进归档，也不会催你）；
- 顶部输入框左边加了「速记」标识，回车只存速记，不再建待办；
- 每条速记可以就地改（点正文、失焦自动保存，`Esc` 放弃，`Ctrl+Enter` 立即保存），可以置顶，可以删除（删完底部能撤销）；
- 想做了就点「转成待办」：第一行当标题、其余行当备注，直接进新建窗口；
- 速记视图有独立搜索框，按正文找；单条上限 4000 字。

数据库升到 v7，老库首次启动自动建 `memo` 表，任务数据一个字都不动。

### 2. 聚焦页小组件看得清了

三个卡的标题（现在 / 本月 / 本周）加粗放大、正文也各放大一档：时钟 44→52px、日期 13→14px、问候 14→15px、底部「接下来」13px。本周柱状图下面不再是「9 10 11」这种数字，改成**星期一 / 星期二 / … / 星期日**，今天那列用强调色加粗；列宽不够时不再换行。

### 3. 字体整体调了一轮

- 字体族补了 `PingFang SC`、`HarmonyOS Sans SC` 兜底，Windows / macOS / Linux 上中文都不至于回落到难看的默认字体；
- 正文行高 1.5 → 1.55，开启字距调整（kern）；
- 详情里的字段标签 11 → 12px，速记、搜索框、按钮等控件统一到 12–14px 一档；
- 所有字号保持整数 px（`ui-audit` 会逐项量：11 / 12 / 13 / 14 / 15 / 26）。

### 4. 顺手修的

- 速记条在「归档 / 统计」以外的视图都保留（它现在是便签入口，不再是「新建待办」的一部分）；
- 速记视图不再显示「＋ 添加」按钮（那里加的是待办，会让人误会）；
- 速记搜不到时给的是空状态文案，而不是一片空白。

## 怎么升级

覆盖安装即可，数据库从 v6 自动升到 v7（新表 `memo`，任务表不动，升级前会留 `workbench.db.pre-v6.bak` 这类备份）。速记和待办是两套数据，想只用速记当备忘录也完全可以。
