# v1.9.2 更新说明

## 这一版：聚焦页的小组件常驻了

上一版里有个取舍：聚焦页的时钟 / 迷你月历 / 本周节奏，只在没做完的待办少于 5 条时出现，条目一多就整体收起。实际用下来这个取舍是错的——**每天都会看一眼的东西，不该因为你今天事多就被藏起来**。这版改成常驻。

### 1. 小组件常驻，条目多时自动收成紧凑模式

- 待办少于 5 条：保持原样，大时钟 + 月历 + 周柱，约占 240px 高度
- 待办 5 条及以上：整排压成**紧凑模式**，约 150px，把高度让给列表，但三张卡一张不少

紧凑模式下做的具体调整：

- 时钟 52px → 30px，日期与问候各降一档，省掉「预计耗时」那一行（它已经挪到视图副标题里了）
- 月历格子从 26px 压到 22px，**圆点改成底色块**——小格子里再放圆点会和下一行数字挤在一起
- 本周柱子的高度收到 42px，「完成 N · 还有 M 条排期」那行照样保留

### 2. 顺带修掉的小问题

- 紧凑模式下「今天」的实心蓝圈会被「今天有完成」的绿色底色盖住，现在今天始终是蓝的
- 空状态（今天没安排）在小组件常驻后也保持一致：三张卡 + 一行「今天还没有安排」+ 三个去处

### 3. 安装程序：文字不再被压住，版本号不再写死

- 安装向导三页的文字改成按实际换行高度依次往下排（原来每段写死 46px 高），提示、报错、完成页的路径都留了足够的行数，不会再出现半截字互相压住
- 安装程序里的版本号改成打包时注入：装完之后 `app\1.9.2\`、`config.json`、注册表里的「显示版本」都是真实版本（以前一律是 1.1.0）
- 新增开发用开关 `--preview=1|2|3 --shot=<png>`，可以在不安装的情况下把任意一页画成图片核对排版

### 4. 发布包精简成两个

从这一版起只发**安装包**和**绿色便携包**：单文件 exe 和单独的 `使用说明.txt` 不再发布（便携包里仍然带 `使用说明.txt`）。GitHub Release 的附件名固定为 `todo-workbench-setup.exe` 与 `todo-workbench-portable.zip`，不带版本号，方便固定链接。

## 怎么升级

1. 设置 → 版本与更新 → 检查更新（或等齿轮上的小红点）
2. 下载安装包，等进度到 100% 并显示「sha256 校验通过」
3. 从托盘退出工作台，运行下载好的安装包覆盖安装

数据在独立目录，升级不覆盖待办、速记和归档。

## 已知限制

- 「待办多」的判定看的是**全部未完成条数**（不区分分类筛选）；在聚焦页按分类筛选时，小组件的紧凑/常规状态不会跟着变
- 紧凑模式下月历不再显示「排期 N 条 · 已完成 M」的页脚，想知道具体数量可以打开日历视图
