# v1.9.0 更新说明

## 这一版：不用再去 GitHub 手动下载了

### 1. 设置里的「版本与更新」

设置面板最下面多了一块：显示当前版本，点**检查更新**就去问一下有没有新版本。有新版本时会把这一版的更新说明直接展开在面板里，下面就是**下载安装包**按钮。

版本信息缓存 6 小时，不会每次开工作台都联网；即使连不上，也只是提示「检查失败」，不影响使用。

### 2. 只走 API 的下载链路

这是这一版花时间最多的地方。之前大家下载更新只能点 GitHub 网页直链，而 `github.com` 在很多网络环境下会超时（我这边实测 5 秒就断）。所以更新检查与下载整条链路改成只走 `api.github.com`，下载时再跟随它 302 到 `release-assets.githubusercontent.com`。

实测同样这 34 MB 的安装包：网页直链超时，走 API 只要 3.4 秒。

### 3. 下载有进度，而且会校验

下载写在 `data/updates/`，边下边显示百分比和已下载大小；下完自动对比 GitHub 每个资产自带的 `sha256`，不一致会直接删掉重来，不会让你装上一个半截文件。下好之后可以一键「打开所在文件夹」。

### 4. 升级不碰你的数据

程序和数据是分开的：数据在 `%LOCALAPPDATA%\TodoWorkbench\data`，安装包只替换程序文件。所以下好安装包之后，关掉工作台、双击安装包覆盖安装就行，待办、速记、归档都不会动。

## 怎么升级

1. 打开设置 → 版本与更新 → 检查更新
2. 有新版本就点「下载安装包」，等进度走完（会显示「sha256 校验通过」）
3. 从托盘菜单退出工作台，运行下载好的安装包覆盖安装

## 已知限制

- **还不会自动替换程序**：目前是「下载 + 校验 + 提示你去装」，把「下完点一下就自动重启并升级」放在下一版，因为要先把替换与回滚做稳
- **安装包没有代码签名**：Windows 第一次运行可能弹 SmartScreen 提示，点「更多信息 → 仍要运行」即可
- 下载的包会一直留在 `data/updates/`，不需要了可以自己删（或者清理时连同旧备份一起删掉）
