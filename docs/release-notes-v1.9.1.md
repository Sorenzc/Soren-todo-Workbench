# v1.9.1 更新说明

## 这一版：把每天都会用到的四件小事补齐

### 1. 多选与批量操作

按住 `Shift` 或 `Ctrl` 点待办可以连选多条（`Shift` 从上次点过的那条开始整段连选）。选中后底部会出现一条操作栏：

- **完成**：逐条走正常完成流程，照常写归档；某一两条失败不影响其他条
- **改到明天 / 改到本周日**：只动日期，不动完成状态
- **打标签**：给这批一起加上标签（只做加法，不会覆盖原有标签）
- **移分类**：一次把这几条挪到另一个分类

选中行有蓝色描边，操作栏上直接写「已选 N 条」；选中的待办被完成或删掉后，会自己从选择里消失。

### 2. 打印今日清单

「今天」视图右上角多了**打印清单**（命令面板里也能搜到）。打印时只留清单本身，一页 A4：

- 标题按到期日排，**逾期在前**，同一天再按优先级
- 每条前面一个方框，可以打印出来直接打勾
- 页脚写「共 N 件 · 预计多久」

这个功能是给「习惯打一张纸带走」的用法准备的，物业、合同、行政这类场景比手机更顺手。

### 3. 启动时静默检查更新

以前只有手动点「检查更新」才会知道有新版本。现在**每天第一次打开**时会静默查一次：

- 联不上、超时，什么都不说，不影响用
- 真有新版本时，只在顶栏右上的齿轮上点一颗**小红点**，点开设置就能看到更新说明和下载按钮

### 4. 每天自动备份

每天第一次启动时自动 `VACUUM INTO` 一份数据库，**只保留最近 7 份自动备份**（手动点「立即备份」的仍保留 14 份）。设置里的「数据位置」会显示上次自动备份的时间。

自动备份失败只会写进日志，绝不挡住启动——它是保险，不是前置条件。

## 怎么升级

1. 设置 → 版本与更新 → 检查更新（或者等顶栏齿轮上的小红点出现）
2. 下载安装包，等进度走完（会显示「sha256 校验通过」）
3. 从托盘菜单退出工作台，运行下载好的安装包覆盖安装

数据在独立目录，升级不覆盖待办、速记和归档。

## 已知限制

- 自动备份只在**启动时**做一次；如果你一天到晚不关工作台，当天就不会再备份。需要立刻备份时可以点设置里的「立即备份」
- 打印清单排版是按 A4 调的，其它纸张尺寸会被浏览器缩放，建议在打印预览里选「A4 / 纵向」
- 批量操作一次最多 200 条（再多分两批，界面会提示）
