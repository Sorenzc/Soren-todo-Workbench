# v1.9.4 更新说明

## 这一版：把安装按钮找回来了

v1.9.3 的安装包有个更严重的问题：**第一页看不到「安装」按钮**。页面内容变长后进了可滚动区域，按钮跟着内容一起被滚到可视区外面，看起来就像「没有下一步」。

### 1. 按钮移到固定底栏

「取消 / 安装」「完成」不再放在可滚动的页面里，而是放进一条**固定在窗口底部**的栏（页面内容再多也滚不到它）。第一页显示「取消 / 安装」，安装中不显示，完成页只显示「完成」。

顺带给向导加了自检：`--preview=1|2|3 --shot=<png>` 除了出图，还会检查每个按钮是否真的可见、是否落在窗口内、页面内容是否超出可视区，任一项不满足就返回非 0 退出码。这一版三页都通过。

### 2. 安装时不再让选数据目录

按你的要求去掉了「数据存到」输入框，改成一句说明：

> 数据默认存在 `C:\Users\<你>\AppData\Local\TodoWorkbench\data`，装好后可在「设置 → 数据位置」看到；想换地方，改安装目录下 `config.json` 里的 `dataDir` 即可（或卸载时保留数据、重装时用 `--data` 指定）。

批量部署时 `--data="D:\TodoData"` 仍然有效，只是不在界面上问。

### 3. 路径校验保持 v1.9.3 的修复

`C:\...`、`D:\待办工作台` 这类正常路径都能过；盘符根目录、多余冒号、保留名（CON/PRN/…）、以点或空格结尾的段名仍会被拦下并给出说明。

## 怎么升级

设置 → 版本与更新 → 检查更新 → 下载安装包 → 托盘退出工作台 → 运行安装包覆盖安装。数据不动，装好后仍指向原来的数据目录。

## 已知限制

- 安装包未签名，UAC 与 SmartScreen 仍可能提示「未知发布者」
- 数据目录改到别处后，旧位置的数据不会自动搬，需要手动复制
- 只支持盘符路径（`D:\...`），网络共享路径（`\\NAS\...`）暂不支持
