## 这一版加了什么

### 1. 置顶

行右侧第一颗按钮、或详情里的「置顶」，可以把一条待办钉在最前面。

- 置顶的任务永远排最前，在「全部待办」里单独成一段、在「聚焦」里单独成一组，不参与到期排序；
- 再点一次取消。

### 2. 「全部待办」按时间七段

原来是混在一起按分数排，现在按状态分段，一眼扫到该先做哪段：

**置顶 → 逾期 → 今天 → 本周 → 本月 → 以后 → 无日期**

每段标题右边带条数和一句说明（比如「拖了很久」「7 天内到期」）。右上角的智能/到期/优先级/创建时间排序照旧可用，只影响段内顺序。

### 3. 组内拖动排序

在「全部待办」里直接把行拖到想要的位置，松手即存。拖过的顺序会一直记住，之后默认就以手动顺序为准（新加的任务排在你拖过的后面）。

### 4. 导出 Markdown

「全部待办」和「某一天」的工具条上多了「导出」，导出的是**当前筛选下**的未完成待办——分类、标签、搜索词都算进去。格式是标准 Markdown：

```
# 待办清单 · 2026-11-10

## 物业运营（2）
- [ ] 确认 A 座消防年检整改回执 · P1 · 📌 置顶 · 到期 2026-11-08 · 子项 1/2
```

贴周报、发给同事、或者存档都行。

### 5. 日历视图

侧栏多了「日历」，不再是原来那个只看得到圆点的浮层：

- **月 / 周**两档切换，‹ › 翻页，「今天」一键回到本周；
- 格子里直接列出当天的待办（最多 3 条，多的显示「还有 N 条」），带分类色点和时间；
- **把条目拖到别的格子就改期**，松手保存；
- 每格右上角显示当天完成了几条 `✓2`；今天那格有蓝框；
- 逾期的格子淡红，页脚会提示「另有 N 条逾期未排进来」，点一下就跳到今天视图处理。

### 6. 关掉页面也能提醒

页面关掉之后，桌面启动器每 30 秒问一次服务端，有到点的提醒就用托盘气泡弹出来（点气泡直接打开工作台）。**这一条要重新装一次新版才会生效**，光覆盖 `public` 目录不行。

## 顺手修的

- 地址栏深链 `?view=calendar` 之前会静默回落成「聚焦」，现在所有视图都能直接链；
- 日历条目从一行截断改成两行，标题能看全；
- 详情里「提醒」输入框太窄，改成独占一行；
- 行标题长了会把 📌 / 子项进度 / ⏰ 挤没，现在小标跟在标题后面、标题自己省略。

## 怎么升级

直接覆盖程序或装新版，数据保留。本版只给任务表加了「置顶」一列，首次启动自动迁移。
