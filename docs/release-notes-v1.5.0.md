## 这一版改了什么

这一版只动界面和交互，数据和功能口径都不变——照着 iOS 的原生观感重做了一遍。

### 1. 配色换成 iOS 系统色

浅色：底色 `#F2F2F7`、卡片纯白、主文字 `#1C1C1E`、强调蓝 `#007AFF`；语义色用系统的红 / 橙 / 绿（`#FF3B30` / `#FF9500` / `#34C759`）。深色同步换成 iOS 深色：卡面 `#1C1C1E`、强调蓝 `#0A84FF`。原来那几支偏暗的自配色全部退场。

### 2. 板块之间用投影分层

侧栏右缘、详情左缘各加一层投影，分组卡片本身也带投影，行与行之间只留 1px 发丝线——原来是三块之间拉硬边线，看着像表格。

### 3. 选中态重做（含圆角修复）

选中的那一行现在是：**蓝色渐变底 + 1.5px 蓝描边 + 左端蓝条**，鼠标没选中时也能一眼分出有没有选中。

同时修掉一个真问题：列表条目的首尾行有圆角，选中描边以前是按矩形画的，选到首尾行时会被卡片裁成直角。现在首尾行跟着卡片圆角走，描边完整贴合。

### 4. 日历视图按 iOS 日历来

- 格子不再一格格描边，改成 1px 发丝线织成的整块网格；
- 今天＝实心蓝圆白字，右上角绿色 `✓n` 是这天完成的条数；
- 逾期日期淡淡一层红，非本月日期淡化；
- 条目是 4px 圆角的小色块（跟着分类色走），最多显示 3 条 + 「还有 N 条」，例行待办的未来几期仍是虚线；
- 顶部「2026 年 11 月 · 第 46 周」，右上角月 / 周切换与「‹ 今天 ›」。

### 5. 其它细节

- 分组标题 13px 半粗，后面的数字变成计数胶囊；
- 侧栏、分类的选中项改成 iOS 那种淡蓝底 + 强调色文字；
- 分段控件（智能 / 按到期 / 按优先级…、月 / 周）换成 iOS 的灰槽 + 白色浮块；
- 按钮、输入框统一 10px 圆角，点按时有 1px 投影；
- 详情「安排」里补了「实际耗时」，和「预估耗时」并排，之前那一格是空的；
- 侧栏「重复」改名「**例行待办**」（新建窗口里那个复选框仍叫「重复」，那是动作，不是入口名）；
- 列表改为 42px 行高，标题、分类、优先级、到期四列对得更齐。

### 6. 双击 start.cmd 不再挂着一个命令行窗口

以前双击 `start.cmd`，那个黑窗口得一直开着——它就是服务本身，关掉窗口等于退出。

现在它只当一秒钟的启动器：在后台把服务拉起来，看到「Workbench started in background」就**自己关掉**，浏览器照常打开。之后开着页面用就行，窗口关不关都不影响。

- 想让服务真正停下：`npm stop`，或 `node scripts\stop.mjs`（会先读 `data\server.pid`，pid 过期就改问服务本身要 pid，不会杀错进程）；打包版用托盘菜单里的「退出」。
- 想在终端里看实时日志、前台运行：`npm start`（这时窗口关掉服务就停，适合开发）。
- 服务已经把日志写进 `data\server.log`，启动失败时 `start.cmd` 会把最后几行直接打出来，方便定位。

## 怎么升级

直接覆盖程序或装新版即可，数据保留，不需要迁移。
