## 这一版加了什么

### 1. 重复：除了每月，还能按天、按周

新建窗口勾上「重复」之后，多了一个「规则」下拉：

| 规则 | 怎么填 | 例子 |
|---|---|---|
| 每月某日 | 选 1–31 号，再选往后铺几期 | 每月 28 号交月度总结 |
| 每 N 天 | 填间隔天数（1–60） | 每 3 天浇一次花 |
| 每 N 周 | 填间隔周数 + 选星期几 | 每周三开例会、每 2 周的周一交周报 |

侧栏「每月例行」这个入口也顺势改名「重复」——它现在真的不只管每月了。

### 2. 每天 / 每周：只留一条，完成就滚

这是和三档规则配套的新做法。

- 每月档和以前一样：一次铺出未来 N 期，每期都是独立一条，可以单独改期、单独取消；
- **每天 / 每周档只建一条「活行」**：勾掉它，这一期写成一条「已完成」并正常归档，活行自己滚到下一期，接着待办。

好处是不会攒出一堆逾期副本。出差一周回来，不是面对 7 条「浇花（已逾期）」，而是只有一条，日期已经滚到今天之后——**中间漏掉的期直接跳过**，不补、不催、不堆积。

侧栏的计数也跟着分了：每月档看「待办 / 已排期 / 已完成 / 共几期」，每天每周档看「待办 1 · 已滚 3 轮」。

### 3. 日历里能看见未来的期

日历视图会把每天 / 每周待办接下来几期画成**虚线条目**——能看见，点一下只提示「这是周期里的未来一期」，不能拖、不能勾。等上一期完成，它才变成实线待办出现在列表里。

### 4. 取消与恢复

「取消未来」对每天 / 每周档的意思就是把那条活行停掉（不再出现在待办里），「恢复」会把它放回来，并且如果日期已经过期，自动滚到今天之后。

### 5. 重新打开已完成的那一期

在「已完成」里重新打开一条历史期，它会脱离系列变成一条普通待办——不会变成该系列的第二条活行跟正在滚的那条抢「下一期」。已经滚过的进度不回滚。

## 数据迁移

老库首次启动会自动升级（第 6 版迁移）：重建周期表、把「同系列同一期唯一」的约束降级成普通索引（每天档同一个月会有多条历史行），迁移前自动备份成 `workbench.db.pre-v6.bak`。待办、分类、归档内容都不动。

## 怎么升级

直接覆盖程序或装新版即可，数据保留。
