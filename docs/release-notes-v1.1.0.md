## 这一版修了什么

主要是「双击 exe，浏览器打不开」这一类问题，另外补了新建待办时几处使用上的硬伤。

### 1. 双击后打不开界面（重点）

根因有三个，都修了：

- **健康检查认不出自己**：服务端有两处 `/api/health`，后注册的那条把 `app` 字段丢了，启动器据此判断「服务没起来」；
- **探测太慢**：每个端口固定等 700ms，十一个端口串起来接近 8 秒，用户体感就是「点了没反应」；改成先用 TCP 探活再请求，正常情况 200ms 内出结果；
- **提权场景下浏览器被拦**：以管理员运行时，用 ShellExecute 打开的浏览器会继承管理员令牌，某些策略下窗口根本不出现在前台。

现在的打开顺序是五级降级，每一级都写进 `logs\launcher.log`：

1. 应用窗口（无地址栏，任务栏显示「待办工作台」和自己的图标）→ 先用你现有的浏览器配置，失败再换工作台独立配置；
2. 系统默认浏览器；
3. `explorer.exe`；
4. `rundll32`；
5. 读注册表里用户设置的主浏览器直接启动。

应用窗口还会核对窗口标题，避免「开了个空白窗口」被当成成功；失败就自动退到下一级，不会再静默失败。

### 2. 新建待办

- **标题输入框**提到最上面，单独一个框、标了「必填」，打开窗口光标直接在里；
- **关联文件**拆成「文件夹…」和「文件…」两个按钮，中文路径不再乱码（之前是把系统选择框的 GBK 输出按 UTF-8 存，再读就成乱码）；
- 历史上已经存坏的关联路径，启动时会自动修，修不了的显示「路径乱码，请重新关联」，不会再让列表渲染报错。

### 3. 任务栏图标

启动器、安装包、托盘、浏览器标签、手机端图标全部换成本项目的图标（蓝色圆角 + 白勾），不再显示默认的空白图标。

## 下哪个

| 文件 | 适合谁 |
|---|---|
| `TodoWorkbench-1.1.0-Setup.exe` | 安装版：能选安装目录、建开始菜单快捷方式、以后能在「设置 → 应用」里卸载（推荐） |
| `TodoWorkbench-1.1.0-Single.exe` | 单文件：双击即用，不写注册表、不建快捷方式 |
| `TodoWorkbench-1.1.0-Portable.zip` | 便携版：解压即用，适合放 U 盘或公司电脑；里面有 `使用说明.txt` |

数据都在本机：安装版固定存 `%LOCALAPPDATA%\TodoWorkbench\data`，便携版存在程序旁的「工作台数据」文件夹。**卸载默认保留数据**，重装、升级都不丢待办。

`SHA256SUMS.txt` 是上面三个文件加使用说明的校验值，下载后可以 `certutil -hashfile <文件> SHA256` 自己核对。

## 已知限制

exe 未做代码签名，首次运行 Windows SmartScreen 会提示「未知发布者」——点「更多信息 → 仍要运行」即可。想要没有这个提示，得用代码签名证书签一次。
