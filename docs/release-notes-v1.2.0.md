## 这一版加了什么

### 1. 子待办

大任务可以拆成几条子项了，在详情面板下面「子待办」那一栏回车就能加。

- 父任务标题后面会显示 `2/3` 这样的进度，一眼看到还剩几条；
- 勾父任务时，没做完的子项会一起完成；反过来勾子项不会动父任务；
- 子项可以单独改日期、优先级、备注、分类；
- **只允许一层**：子项下面不能再挂孙项，列表里不会出现看不见的第三层；
- 删父任务会把子项一起放进「已删除」，撤销时一起回来；
- 列表、日历、统计、归档都只算一级任务，子项不会单独冒出来占行。

### 2. 到期提醒

详情面板「安排」里多了一个「提醒」，和截止日期互不影响——截止是「什么时候该交」，提醒是「什么时候拍我一下」。

- 页面开着时每 20 秒问一次服务端，到点右下角弹提示；在「设置 → 开启系统通知」授权后还会发 Windows 系统通知；
- **同一条提醒只会响一次**：服务端用 `remind_fired` 抢占，多个窗口/托盘不会重复弹；
- 迟到超过 15 分钟的只标记、不补发（免得开机一口气炸出十条）；
- 改了提醒时间会重新武装。

### 3. 编号列表拆成多条

新建窗口的标题框里写：

```
1. 收物业费台账
2. 核对消防维保合同
3. 发月度总结
```

点「创建」会自动拆成三条待办，省得一条条开窗口。少于两个编号就按普通标题建一条；`3.14`、`12.5%` 这种小数不会被误拆。

### 4. 逾期一键完成

「今天」视图的逾期组右上角多了「一键完成 N 条」。

- 确认框只说你真的会踩到的事：里面有几条是重复待办（只完成这一期）、有几条带子待办（子项会一并勾上）；
- 中途某一条失败不中断，做完告诉你成功几条、哪几条没成。

### 5. 归档升级

完成父任务时，子项会以 `- [x] 标题` 的清单写进同一个归档 md，表头里多了「提醒」和「子项 2/2 已完成」两行。子项不单独生成归档文件。

## 怎么升级

数据全在本机，直接覆盖程序或装新版即可，待办、分类、归档都保留。本版没有改数据目录结构，只加了列，首次启动会自动迁移。
