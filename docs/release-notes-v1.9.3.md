# v1.9.3 更新说明

## 这一版：修掉安装包「路径里有 Windows 不允许的字符」

v1.9.2 的安装包有个会把安装卡死的 bug：**不管默认路径还是自己选的路径，一确认就报「这个路径里有 Windows 不允许的字符」**，等于装不上。

### 1. 路径校验重写

根因是校验把盘符后面的那个冒号也当成了非法字符——`C:\` 里的 `:` 是必须的，但旧逻辑一律拒绝，所以任何绝对路径都过不了。

现在的规则是：

- 必须是完整的盘符路径（`X:\...`），不能是相对路径，也不能是 `\\服务器\共享` 这类网络/设备路径
- 不能直接放在盘符根目录（`C:\` 会被拒绝，并给出明确提示）
- 冒号只允许出现在盘符后面
- 每段名字不能以空格或点结尾，不能用 `CON`/`PRN`/`AUX`/`NUL`/`COM1`…`COM4`/`LPT1`…`LPT3` 这些保留名
- 其余老规则保留：不能是已存在的文件、路径不能过长、所在盘剩余空间要够、要能在那目录里写文件

除了提示文字，判定顺序也改了：**先按用户输入的原样检查**，再做规范化。因为 Windows 会把 `C:\con` 变成设备路径 `\\.\con`、把 `C:\foo.\bar` 悄悄改成 `C:\foo\bar`，用规范化后的结果去判断会漏掉这些坑。

### 2. 数据目录也能自己选了

安装页新增「数据存到」一行，默认 `%LOCALAPPDATA%\TodoWorkbench\data`，可以点「浏览…」换位置，也可以用 `--data="D:\我的待办数据"` 静默安装。安装位置和数据目录不允许填成同一个。

这条路径会写进 `config.json` 的 `dataDir`，启动器按它设置数据库、归档、备份、日志的位置，所以从装好第一天起数据就落在你选的地方。卸载时仍然可以选择保留数据。

### 3. 「所有用户安装」不再提发布者

选了「为所有用户安装」后，原来那句「发布者显示为「陈春天的哥哥」」已经删掉，改成「这台电脑上的每个账户都能用；Windows 弹出「用户账户控制」时点「是」继续。」

需要说明的是：安装包没有代码签名，Windows 的 UAC 弹窗里仍会写「未知发布者」——这一行由 Windows 自己填，安装器改不了。

## 怎么升级

1. 设置 → 版本与更新 → 检查更新（或等齿轮上的小红点）
2. 下载安装包，等进度到 100% 并显示「sha256 校验通过」
3. 从托盘退出工作台，运行下载好的安装包覆盖安装

覆盖安装不会动数据，装好后仍指向原来的数据目录。

## 已知限制

- 只支持本地盘和移动硬盘这类盘符路径；网络共享路径（`\\NAS\...`）暂不支持
- 数据目录换成新位置后，旧位置的数据不会自动搬过去，需要手动复制
- 安装包未签名，UAC 与 SmartScreen 仍可能提示「未知发布者/已保护你的电脑」
