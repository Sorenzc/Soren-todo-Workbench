## 这一版改了什么

这一版解决「一天还没开始、列表是空的」和「想到一件事，懒得开弹窗」两件小事。数据口径不变（库结构没动，不需要迁移）。

### 1. 聚焦页多了三张卡（待办少时才出现）

这半年最常听到的反馈是：忙起来列表塞满，空下来聚焦页又空得像没做完。现在聚焦页会看情况换脸：

- **待办 5 条以上**：和以前一样，只给列表，不占地方；
- **待办 4 条及以下**：列表上面多三张卡——**现在**（大号时钟 + 日期 + 问候 + 今天预计要花多久 + 「接下来」那一条，点一下直接开详情）、**本月**（迷你月历，有排期的日子带圆点，完成过的圆点变绿，今天实心蓝圈，点任意一天跳过去）、**本周**（周一到周日七根柱子，柱高是当天有几件事，整天全部完成变绿）；
- **一条都没有**：列表位置换成「今天还没有安排」，配「记一条 / 看看全部待办 / 今日简报」三个入口。

「今天要花多久」是把今天到期任务的预估耗时加起来，所以**给待办填预估耗时是有回报的**。这一周一次都没排期时，本周卡不会画七根空柱子，而是一句「这周还没排期，日子是空的也挺好」。

### 2. 每个视图顶部都有速记框

写一句回车，直接进「收件箱」，不开弹窗。支持老的那套快速语法：

- `!p1` / `!p0` / `!p3` 设优先级；
- `@今天` `@明天` `@周五` `@3天后` `@2026-11-20` 设日期；
- `#合同` 加标签，能对上分类名就直接归到那个分类。

`C` 键把光标送进速记框，`Esc` 退出（已经写了一半的字不会丢）。速记框和「＋ 添加」一样只在能添加待办的视图出现，统计、已完成、归档这些地方不显示。

### 3. 键盘流

不用离开键盘就能干完最常见的事（都在输入框外、没有弹窗时生效）：

| 键 | 作用 |
| --- | --- |
| `N` | 新建待办（打开完整表单） |
| `C` | 光标进速记框 |
| `/` | 打开搜索 / 命令面板 |
| `E` | 完成当前选中的待办 |
| `P` | 置顶 / 取消置顶 |
| `Delete` | 删除当前选中的待办（可撤销） |
| `[` `]` | 上下换选中 |
| `Esc` | 逐层退出：速记框 → 详情 → 弹窗 → 搜索 |

底部状态栏右侧也把常用的几个键列出来了，省得记。

### 4. 今天的预计耗时进了标题

「聚焦」和「今天」的副标题现在会带一句「预计 2 小时 5 分」，和小组件里那个数字同源。超过你自己一天的可用时间也不会报警——先把账算清楚，怎么排还是你定。

### 5. 打包脚本与版本号

- `package.json` 是唯一版本来源，打包脚本、`/api/health`、安装包文件名都跟着它走，以后改一处就够；
- 顺带修了两个只有干净 clone 才会踩的打包问题：`build\app.ico` 不在仓库里（已补多尺寸图标，缺失时自动降级为无图标编译）、`dist\` 目录不存在导致复制失败（改为自动创建）。

## 怎么升级

覆盖安装或替换程序即可，数据保留，不需要迁移（库结构这一版没改，仍是 v6）。
